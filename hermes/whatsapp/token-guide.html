🔑 Cómo crear tu token del aula

Una sola vez. Te toma un minuto.

1

Toca el enlace «tu perfil del aula» del mensaje. Si te pide entrar, usa tu cuenta de ESPOL.

2

Baja hasta «Integraciones aprobadas» y toca «+ Nuevo token de acceso».

Configuración

Integraciones aprobadas

+ Nuevo token de acceso

3

En «Propósito» escribe Vinci. Deja la fecha vacía y toca «Generar token».

Nuevo token de acceso

Propósito

Vinci

Fecha de vencimiento

(vacío)

Cancelar Generar token

4

Copia el token: las letras y números largos. Mantenlo presionado y toca «Copiar».

Detalles del token de acceso

Token

aB3dE…(unos 64 caracteres)…xY9z
5

Vuelve a este chat, toca «🔑 Abrir formulario», pega el token y toca «Enviar cifrado a Vinci».

🔑 Tu token del aula…
🔗 🔑 Abrir formulario
🔒 Tu token se cifra en tu celular. Vinci lee tu aula y solo entrega algo cuando tú tocas «Entregar».
