Cómo funcionan el sondeo y el token

Sondeo. Cada 10 minutos, un servicio aparte lee el aula de cada persona con Vinci, una por una: tú primero, después cada amigo. Compara con lo que vio antes y manda un aviso por cada tarea, nota o fecha nueva.

Renovación del token. ESPOL invalida cada token a la hora. A los 40 minutos, Vinci usa el token actual para crear el siguiente y borra el viejo: la cadena sigue sola, sin que nadie haga nada.

Token cortado. Si Vinci pasa más de una hora sin renovar (el servidor caído o un deploy largo), el token vence y no queda con qué crear otro. Solo la persona lo arregla: crea un token nuevo en el aula y lo manda con el formulario. Su Vinci se lo pide solo, con el botón, una vez al día entre las 8:00 y las 21:00.

Sin conectar. Recibió la invitación (el video, la página de funciones y el enlace), pero nunca mandó su token. El enlace sirve un día; si escribe /token, le llega otro. Hasta entonces Vinci no usa el modelo con esa persona.
